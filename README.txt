PERIN - SITE DA LOJA
=====================

ARQUIVOS
- index.html
- style.css
- script.js
- pasta images/

COMO ABRIR NO VISUAL STUDIO CODE
1. Extraia o arquivo ZIP.
2. Abra o Visual Studio Code.
3. Clique em File > Open Folder.
4. Escolha a pasta "perin_loja".
5. Abra o arquivo index.html.
6. Para visualizar, você pode clicar duas vezes no index.html ou usar a extensão Live Server.

IMPORTANTE: TROCAR O WHATSAPP
Abra o arquivo script.js e procure:

const WHATSAPP_NUMBER = "5549999999999";

Troque pelo número verdadeiro da loja.
Use apenas números:
55 + DDD + número

Exemplo:
5549999999999

COMO TROCAR PRODUTOS
No arquivo script.js existe uma lista chamada "products".
Você pode trocar:
- name
- price
- description
- badge
- image

COMO TROCAR AS FOTOS
Coloque novas imagens dentro da pasta "images".
Depois altere o caminho da imagem no produto correspondente em script.js.

Exemplo:
image: "images/minha-camisa.jpg"

Observação:
As camisetas que acompanham o projeto são ilustrações provisórias para o site já abrir bonito.
Substitua por fotos reais da Perin quando tiver as imagens.
